# NGINX Reverse Proxy Template

Production-ready NGINX Reverse Proxy using Docker.

## Features
- NGINX as Reverse Proxy
- Clean traffic routing
- Security headers
- Dockerized backend
- Easy to extend (SSL, load balancing)

## Run
```bash
docker-compose up --build
```
